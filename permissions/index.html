    Permissions & Authorization Matrix¶

    Roles¶

    The system uses a Role-Based Access Control (RBAC) system with three distinct roles.

    1. Super Admin¶

    Scope: Platform-wide administration.

    Key Capabilities:

    • Tenant Management: Full control (Create, Read, Update, Delete) over all tenants.
    • User Management: Can manage Admin users across the system.
    • Catalog Management: Exclusive rights to create, update, and delete global resources including Genres, Platforms, and the Global Game Catalog.
    • System Access: Unrestricted access to most system resources, with the exception of private user data (e.g., User Games) where explicit access is not required.

    2. Admin (Tenant Admin)¶

    Scope: Tenant-level administration.

    Key Capabilities:

    • Tenant Management: Read-only access to their own tenant's details. Cannot see other tenants.
    • User Management: Full control over users (Gamers) within their own tenant. Cannot manage Super Admins or themselves via the User API.
    • Tenant Games: Full control to add or manage games specific to their tenant.
    • Catalog Access: Read-only access to the Global Game Catalog, Genres, and Platforms.
    • User Games: Can view and manage game lists for users within their tenant.

    3. Gamer¶

    Scope: Personal user data.

    Key Capabilities:

    • Self Management: Can manage their own profile and password.
    • User Games: Full control (Create, Read, Update, Delete) over their own personal game list.
    • Tenant Games: Read-only access to games available in their tenant.
    • Catalog Access: Read-only access to Genres and Platforms. No access to the raw Global Game Catalog.
    • Restrictions: Strictly isolated from other users' data and administrative functions.

    Permission Matrix¶

    Resource Super Admin Admin Gamer
    Tenants Full CRUD Read (own only) No access
    Users CRUD (Admins) CRUD (tenant users) Read/Update (self)
    Genres Full CRUD Read-only Read-only
    Platforms Full CRUD Read-only Read-only
    Games (Catalog) Full CRUD Read-only No access
    Tenant Games Full CRUD CRUD (own tenant) Read (own tenant)
    User Games No access* CRUD (tenant users) CRUD (own games)
    User Game Notes No access* CRUD (tenant users) CRUD (own notes)
